# 콘텐츠 작성 가이드

## 쉬운 한국어 설명

- 한 문장에는 한 가지 생각만 담고, 가능한 한 짧은 능동문을 씁니다.
- 용어보다 쓰는 상황을 먼저 설명합니다. 용어가 필요하면 바로 쉬운 말로 풀이합니다.
- 기본 설명과 “더 쉽게” 설명은 실제로 난이도가 달라야 합니다. 쉬운 설명은 가장 짧은 형태와 한 가지 예에 집중합니다.
- 영어 수준과 한국어 설명 수준을 섞지 않습니다. A1 영어라도 한국어 설명은 사용자가 고른 수준에 맞춥니다.

## 베트남어 지원

- 한국어 설명을 그대로 기계적으로 옮기지 말고, 짧고 자연스러운 베트남어로 같은 핵심을 전달합니다.
- 새로운 교육 내용을 베트남어 영역에만 두지 않습니다.
- 항상 접힌 상태를 기본으로 하고, 먼저 쉬운 한국어 도움을 선택할 수 있게 합니다.
- 베트남어 화자의 예상 간섭 오류가 확실할 때만 간단히 언급합니다.

## 자연스러운 예문

- 성인이 실제로 말하거나 쓰는 일상 장면을 사용합니다.
- 목표 표현의 대표 연어를 반복하되 이름, 장소, 시간, 목적을 바꿉니다.
- 문법적으로 가능한 문장보다 실제 빈도가 높은 문장을 우선합니다.
- 한 레슨 안에서 첫 만남, 직장, 이동, 집, 메시지 등 문맥을 분명히 표시합니다.
- 저작권 있는 교재 문장을 복제하지 않고 직접 작성합니다.

## 수준과 선행 규칙

- CEFR A1에서는 짧은 현재형 문장, 고빈도 어휘, 즉각적인 개인 정보를 우선합니다.
- 새 문법은 레슨당 최대 두 개이며, 선행 문법 없이 설명 가능한지 확인합니다.
- `prerequisites`에는 실제로 이해에 필요한 앞 레슨 ID만 넣습니다.
- 인식 → 회상 → 산출 순서로 구성하고, 마지막 숙달 확인에는 둘 이상의 기능을 섞습니다.
- 한 영역이 약해도 레슨 통과를 막지 말고 해당 목표를 복습 카드로 연결합니다.

## 검수와 AI 콘텐츠

AI가 만든 초안을 검수 없이 교육과정에 게시하지 않습니다. 모든 문장과 설명은 영어 교육 경험이 있는 사람이 정확성, 자연스러움, 문화적 맥락, 난이도, 번역 일치 여부를 확인해야 합니다. 스키마 통과는 편집 검수를 대신하지 않습니다.
